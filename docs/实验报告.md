### 一、实验目标

使用多种分类算法与调参技巧对测试结果进行优化。

### 二、知识查询&概念理解

1. **TF-IDF**：用于将文本转化为向量表示。TF（词在文档内的频率）乘 IDF（log(语料大小 / 出现该词的文档数)），再 L2 归一化。一个较高的tf-idf值表示该词在该文档中出现次数多且在全局中出现次数较少。

2. **四种算法原理**：
   - **朴素贝叶斯**：贝叶斯定理 + 条件独立假设，秒级训练，传统文本 baseline
   - **SVM**：最大化分类间隔，文本分类上线性核几乎总是最优
   - **逻辑回归**：线性 + softmax + 交叉熵 + L2，输出概率、稳定、可解释
   - **MLP**：多层非线性网络，能学特征交互但训练慢、调参难

### 6.思考与拓展

#### 问题 1：为什么 SVM 和 LR 在这个数据集上表现好？

文本数据"高维 + 稀疏"的特性，恰好匹配线性模型的归纳偏置。

(1) 几何上的"自由度过剩"

在 d ≫ n 的空间里，任意一组样本几乎都线性可分——维度足够多，就能"摊开"任何一团点。线性模型在这片空间里足够用，不需要非线性也能划出清晰边界。

(2) 稀疏性带来的两个好处

- 多数特征为 0：50000 维里非零占比仅 ~0.46%，权重矩阵实际只被少量 token 激活 → 等价于隐式正则化
- 特征之间近似正交：稀疏向量内积趋近于 0，SVM 的"最大间隔"几何意义明确

#### 问题 2：MLP 能否通过调结构/超参数进一步提升？是否过拟合？

当前配置

MLPClassifier(hidden_layer_sizes=(100,), max_iter=100,

​               alpha=1e-4, learning_rate_init=1e-3, batch_size=200)

- 第一层权重 = 50000 × 100 = 5,000,000 个参数
- 训练样本 5894 条，参数/样本比 ≈ 848

这个比例已经偏高，任何"加深/加宽/加 epoch"都会放大过拟合。

**当前瓶颈在特征，不在模型**

MLP 的本质是：

softmax(W₂ · ReLU(W₁x + b₁) + b₂)

- 第一层已经在做"降维"，把 50000 维压到 100 维；
- 100 个神经元能表达的非线性非常有限；
- 想要有0.5 pp 以上的提升，必须改特征或加大隐层（但代价是大量训练时间 + 显著过拟合风险）。

#### 问题 3：除 TF-IDF 之外还有哪些文本表示方法？

离散词袋：把文档看作一个词的集合，忽略词序和语法结构，用词频或词的重要性来描述文档。

静态词向量：通过大量无标注文本预训练，把每个词映射为一个低维稠密向量，让语义相近的词在向量空间里位置相近，表示结果是低维稠密向量。代表Word2Vec

上下文相关：词的表示不再固定，而是根据当前句子的上下文动态生成，使用深度神经网络让同一个词在不同语境下拥有不同向量。代表BERT

稀疏-稠密混合与检索增强：结合稀疏表示的可解释性和稠密表示的语义能力，针对检索和大规模语义匹配场景做专门优化。
